# DS-pwsh Terminal Bridge

Расширение для Chrome/Chromium, которое связывает реальный DOM страницы
DeepSeek с локальным терминалом. Оно не исполняет JavaScript-блоки «инструментов»
и не использует Electron. Распознаются только блоки кода ассистента с меткой
`pwsh` на Windows и `bash` на Linux/macOS.

## Локальный запуск

1. Запустите мост из той папки проекта, в которой должен работать ИИ:

   ```sh
   cd /path/to/your/project
   node /path/to/DS-pwsh/browser-extension/bridge/host.js
   ```

   В Windows — эквивалент в PowerShell:

   ```pwsh
   Set-Location C:\path\to\your\project
   node C:\path\to\DS-pwsh\browser-extension\bridge\host.js
   ```

   При старте мост сам открывает `https://chat.deepseek.com/` в браузере
   по умолчанию (`cmd.exe start` в Windows, `open` в macOS, `xdg-open` в Linux).
   Отключить авто-открытие: `DS_PWSH_NO_OPEN=1`. Переопределить команду
   открытия в Linux: `DS_PWSH_OPEN_CMD=...`.

   Мост пишет в консоль каждую выполненную команду с подсветкой синтаксиса.
   Для этого используется [Rich](https://github.com/Textualize/rich) через
   небольшой Python-хелпер (`bridge/rich-log.py`). Один раз создайте локальное
   виртуальное окружение:

   ```sh
   cd /path/to/DS-pwsh/browser-extension/bridge
   uv venv .rich-venv
   uv pip install --python .rich-venv/bin/python rich
   ```

   В Windows сначала установите Python 3.8+ и [uv](https://docs.astral.sh/uv/)
   (например, `winget install Python.Python.3.12` и
   `winget install astral-sh.uv`), затем из PowerShell:

   ```pwsh
   cd C:\path\to\DS-pwsh\browser-extension\bridge
   uv venv .rich-venv
   uv pip install --python .rich-venv\Scripts\python.exe rich
   ```

   Виртуальное окружение игнорируется git. Если Rich не установлен, мост
   откатывается на обычные текстовые логи `[DS-pwsh] >>> ...`. Отключить Rich
   принудительно: `DS_PWSH_NO_RICH=1`; указать другой интерпретатор:
   `DS_PWSH_PYTHON=/path/to/python`.

   Терминал должен оставаться открытым. Мост автоматически выбирает свободный
   порт в диапазоне `49152-49183` и печатает адрес. Требуется Node.js 18+.

   Перед запуском можно задать минимальную задержку перед отправкой результата
   в DeepSeek. По умолчанию 0, допустимо от 0 до 180000 мс. Мост возвращает
   результат команды сразу; задержку применяет расширение в браузере, поэтому
   мосту не нужно держать открытый запрос во время кулдауна:

   ```sh
   DS_PWSH_MIN_SEND_DELAY_MS=10000 node /path/to/DS-pwsh/browser-extension/bridge/host.js
   ```

   В PowerShell: `$env:DS_PWSH_MIN_SEND_DELAY_MS = "10000"` перед запуском
   `node`. Значение отдаётся мостом в `/health` для диагностики; фактическая
   пауза перед отправкой настраивается в popup расширения
   («Кулдаун отправки»).

2. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**,
   выберите **Загрузить распакованное** и укажите папку `browser-extension`.
   После изменения файлов расширения нажмите **Reload** на его карточке и
   обновите вкладку DeepSeek, чтобы загрузился новый content script.
3. Откройте или обновите `https://chat.deepseek.com/`. Popup должен показать
   подключение к локальному мосту. Если страница сообщает, что API расширения
   недоступно, нажмите **Reload** на карточке расширения и снова обновите
   вкладку DeepSeek: старый content script может остаться привязанным к уже
   открытой вкладке после перезагрузки расширения.
4. При необходимости укажите рабочую папку проекта в popup. Если оставить поле
   пустым, мост использует папку, из которой он был запущен.
5. Скопируйте инструкцию из popup расширения и вставьте её в чат. DeepSeek
   может вернуть несколько терминальных команд отдельными блоками `pwsh` или
   `bash`; расширение выполняет их последовательно и отправляет все результаты
   вместе. Ведущий маркер списка Markdown перед командой игнорируется.

## Поведение при выполнении

Автоматическое выполнение включено по умолчанию, как и возврат вывода команд в
текущий чат. Отключите это в popup, чтобы новые блоки команд не запускались.
**Подтверждать каждую команду** включено по умолчанию; отключите, чтобы блоки
выполнялись сразу, без диалога подтверждения. Кнопка **Пропустить** пропускает
только эту команду; последующие команды в том же ответе всё равно выполняются
по порядку. Команда выполняется от имени текущего пользователя ОС, с доступом
к его файлам и правам; не включайте автоматическое выполнение для недоверенных
чатов. Таймаут каждой команды — 60 секунд, вывод ограничен 1 МиБ.

Расширение само находит небольшой диапазон локальных портов моста; настраивать
порт вручную не нужно. Мост принимает запросы только от origin расширения
Chrome и отклоняет оболочки, не соответствующие ОС хоста. Расширение
внедряется только на `chat.deepseek.com`. Кнопка **Закончить сессию** удаляет
открытый чат из боковой панели DeepSeek после повторного подтверждения.


## Готовые бинарники

При каждом пуше в `main` (и по тегу `v*`) собираются standalone-исполняемые
файлы моста и прикрепляются к GitHub Release:

- `ds-pwsh-bridge-arch-x64` - Arch Linux (сборка в контейнере Arch)
- `ds-pwsh-bridge-ubuntu-x64` - Ubuntu
- `ds-pwsh-bridge-win-x64.exe` - Windows

Скачайте файл для своей платформы, сделайте исполняемым (`chmod +x` в Linux)
и запускайте из папки проекта вместо `node .../host.js`. В этих исполняемых
файлах Rich-логирование отключено (Python-хелпер не встроен) - используется
обычный текстовый лог. Само расширение не входит в бинарник - загружайте
`browser-extension/` в Chrome как распакованное, как обычно.
